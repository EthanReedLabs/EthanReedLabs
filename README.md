## Featured Work

### [sulde-cc showcase](https://github.com/EthanReedLabs/sulde-cc-showcase)

A public showcase for a private Claude Code multi-end coordination framework.

**Core idea:** split one large AI coding session into structured roles, then use artifacts instead of session memory to carry work across people, platforms, and time.

| Area | Details |
|---|---|
| Skills | 17 role-specific Claude Code skills |
| Hooks | 11 enforcement hooks for task quality and workflow boundaries |
| Templates | Android / iOS / Flutter / HarmonyOS NEXT |
| Methodology | 7-layer artifact-over-memory pyramid |
| Knowledge loop | Bugbook, ADRs, handoff, and case-study sedimentation |
